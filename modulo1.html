Módulo 1 · Framingham + R + Copilot

Ruta de decisión estadística en Ciencias de la Salud

Conociendo los datos antes de analizar

Exploración de una base clínica con R y GitHub Copilot

La IA puede ayudar a escribir código; el investigador debe formular la pregunta e interpretar el resultado.

Propósito del módulo

Lo que sí haremos

  • Conocer la base Framingham.
  • Cargar datos desde GitHub.
  • Usar Copilot como apoyo.
  • Evaluar estructura, calidad y descriptivos.
  • Formular preguntas de investigación.

Lo que no haremos aún

  • No elegiremos pruebas estadísticas.
  • No haremos inferencia.
  • No construiremos modelos predictivos.
  • No aceptaremos respuestas de IA sin revisión crítica.

Regla de oro

Nunca ejecutaremos código generado por IA sin saber qué pregunta intenta responder.

Flujo de trabajo del módulo

Pregunta del investigador → Prompt para Copilot → Código en R → Resultado → Interpretación → Nueva pregunta

Este flujo evita que la capacitación parezca una clase de programación o una demostración pasiva de IA.

Primer contacto: cargar la base desde GitHub

Usaremos una fuente reproducible para que todos trabajen sobre el mismo archivo.

Prompt para Copilot 1
Tengo una base de datos CSV disponible en esta URL: https://raw.githubusercontent.com/waranapa/kaggle/main/data Genera código en R para cargarla con readr, guardarla como un objeto llamado framingham y verificar que fue importada correctamente.

Código esperado

library(readr) url <- "https://raw.githubusercontent.com/waranapa/kaggle/main/data" framingham <- read_csv(url) dim(framingham) head(framingham)

No es necesario memorizar el código. La meta es entender qué hace.

Calidad de datos: valores faltantes

Un análisis serio no comienza comparando grupos. Comienza preguntando si la base está completa.

Pregunta crítica

¿Podemos ignorar los datos faltantes?

Respuesta académica: depende del porcentaje, de la variable afectada, del objetivo del análisis y del mecanismo que produjo esos faltantes.

Visualización exploratoria

Los gráficos ayudan a detectar distribución, asimetría, valores extremos y posibles errores.

Prompt para Copilot 6
Genera gráficos en R con ggplot2 para explorar la distribución de age, totChol, glucose y sysBP en la base framingham. Usa histogramas con títulos claros, etiquetas en español y un tema visual limpio.

No preguntamos solamente: “¿es normal?”

Preguntas más útiles

  • ¿Dónde se concentra la mayoría de valores?
  • ¿Hay asimetría?
  • ¿Hay valores extremos?
  • ¿Existen valores clínicamente poco plausibles?

Interpretación clínica

La distribución de una variable debe leerse con criterio estadístico y conocimiento clínico.

EDA orientado al desenlace

Después de describir la población completa, podemos mirar descriptivamente a quienes desarrollaron o no enfermedad coronaria.

Prompt para Copilot 7
Genera código en R para comparar descriptivamente la edad, presión sistólica, colesterol total, glucosa, tabaquismo, diabetes e hipertensión según la variable TenYearCHD. No realices pruebas estadísticas; solo descriptivos por grupo.

Importante: todavía no estamos haciendo inferencia

Sí estamos haciendo

  • Exploración.
  • Descripción.
  • Detección de patrones.
  • Generación de preguntas.

Aún no estamos haciendo

  • Pruebas de hipótesis.
  • Conclusiones causales.
  • Modelos predictivos.
  • Decisiones clínicas definitivas.

Del hallazgo descriptivo a la pregunta

Ejemplo: si observamos que quienes desarrollaron CHD parecen tener mayor edad promedio...

Pregunta de investigación posible:

¿La edad difiere entre los pacientes que desarrollaron enfermedad coronaria a 10 años y quienes no la desarrollaron?
